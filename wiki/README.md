# Pixalo Wiki

Welcome to the official Pixalo documentation! This guide will help you get started with Pixalo, a powerful 2D game engine for JavaScript.

---

## 🎮 Before You Start

**We highly recommend visiting our [Examples Gallery](https://pixalo.xyz/examples)** to see Pixalo in action and get a feel for the engine's capabilities. Exploring live examples is the best way to understand the API and learn common patterns.

## 💡 Tips for Success

1. **Start Simple** - Don't try to learn everything at once. Build small projects first.
2. **Use Examples** - Check [pixalo.xyz/examples](https://pixalo.xyz/examples) when stuck.
3. **Experiment** - The best way to learn is by trying things out.
4. **Read the Docs** - Each class documentation includes detailed usage examples.
5. **Check CHANGELOG** - Stay updated with new features and breaking changes.
